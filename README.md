# BrightSteps Learning

A complete, dependency-free starter website for an accessible K–6 learning platform.

## Included

- K–6 grade selection
- Reading, Math, Science, Writing and Life Skills
- 21 sample interactive activities
- Child-friendly activity flow
- Progress tracking using browser localStorage
- Parent/Teacher dashboard
- Downloadable text progress report
- Large text
- High contrast
- Reduced motion
- Calm mode
- Keyboard focus states
- Skip navigation
- Responsive mobile/tablet/desktop layout

## Run locally

No build system is required.

1. Open `index.html` in a browser.
2. Or serve the folder with any static web server.

Example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy

This project is static HTML/CSS/JavaScript, so it can be deployed to any static hosting provider.

## Important production work

Before using this with real children, add a proper backend, authentication, parental consent/authorization flow, privacy policy, terms, data retention controls, secure storage, accessibility testing with users, and age-appropriate privacy/compliance review. Do not put real child-identifying information into the current localStorage demo.
